Setup guide

Chicago Budget Dashboard

Explore Chicago's adopted budget — who gets what, what City Council changed, and where the money comes from.

Quick start

If dashboard.html is already in this folder, just open it. No install, no server.

Open the dashboard

Keep the src/ folder next to dashboard.html — the page loads styles and scripts from there. It has two pages: At a glance and Ordinance.

Rebuild or refresh data

You only need Python when you want to rebuild the dashboard or pull fresh data from the city API.

python3 run.py

Mac/Linux:

chmod +x run.sh
./run.sh

Download new data from the portal, then rebuild:

python3 run.py --refresh

1. Install Python (for rebuilds)

You need Python 3.10 or newer.

python3 --version

2. Chicago Data Portal credentials

Refreshing data requires a free account on the Chicago Data Portal.

  1. Sign in at data.cityofchicago.org.
  2. Open Developer Settings.
  3. Create an App Token and copy it.
  4. Use the same email and password you use to sign in.

Credentials live in a local .env file only. Never commit or share that file.

3. Create .env

cp .env.example .env
  • SOCRATA_APP_TOKEN App token from Developer Settings
  • SOCRATA_USERNAME Your portal email
  • SOCRATA_PASSWORD Your portal password

4. New budget year

  1. Update dataset IDs in .env or src/pipeline/config.py, and set BUDGET_YEAR if needed.
  2. Run python3 run.py --refresh to download and rebuild.

What's in this folder

  • README.md — the project readme
  • dashboard.html — the dashboard (At a glance + Ordinance)
  • START_HERE.html — this guide
  • run.py / run.sh — rebuild or refresh
  • src/ — code, styles, cached data (see src/README.md)

Sharing with someone else

Send the whole project folder, or at minimum:

  • dashboard.html
  • src/app.css
  • src/dashboard.js
  • src/glance.js

They can open dashboard.html immediately. Include START_HERE.html if they may need to refresh data later.
